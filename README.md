# Kevin Rodríguez — Portfolio

Portfolio profesional de **Kevin Rodríguez**, Ingeniero Informático y Frontend Engineer especializado en desarrollo web, arquitectura frontend y construcción de productos digitales.

## Descripción

Este proyecto presenta mi experiencia profesional, proyectos relevantes, principales tecnologías y enfoque de desarrollo.

El portfolio está pensado para mostrar no solo las soluciones construidas, sino también la forma en que abordo problemas de software desde:

- arquitectura;
- diseño de componentes;
- buenas prácticas;
- rendimiento;
- accesibilidad;
- mantenibilidad;
- experiencia de usuario.

## Arquitectura

El proyecto utiliza **Next.js App Router** y una arquitectura frontend orientada a responsabilidades claras, composición y reutilización razonable.

Se prioriza:

- Clean Code;
- principios SOLID;
- bajo acoplamiento;
- alta cohesión;
- composición;
- componentes reutilizables;
- tipado estricto;
- accesibilidad;
- responsive design;
- SEO;
- performance.

La arquitectura debe mantenerse proporcional al tamaño y complejidad real del proyecto, evitando sobreingeniería.

## Diseño

La interfaz del portfolio fue diseñada previamente en **Claude Design**.

El diseño funciona como referencia visual para la implementación y se busca mantener alta fidelidad respecto a:

- composición;
- tipografía;
- colores;
- spacing;
- proporciones;
- componentes;
- responsive behavior;
- interacciones.

La implementación final se realiza de forma nativa con React y Next.js, evitando depender del HTML generado por la herramienta de diseño.
